# Fila Fácil — versão 5

Aplicativo Android oficial do Fila Fácil.

## Alterações da v5

- `versionCode 5` e `versionName 5.0`.
- Nome visível mantido como **Fila Fácil**.
- Pacote mantido como `com.castprods.filafacil`.
- WebView apontando para a produção pública do Fila Fácil.
- Tela de abertura e tela offline redesenhadas.
- Upload de foto pelo seletor nativo do Android.
- GPS solicitado apenas quando a página oficial solicitar localização.
- Navegação interna restrita ao domínio oficial do Fila Fácil.
- Links externos abrem fora do WebView.
- HTTP, conteúdo misto e erros SSL são bloqueados.
- Safe Browsing ativado, backup desativado e certificados limitados ao sistema.

> Esta versão usa uma nova assinatura porque a chave privada da v4 não estava disponível no pacote enviado.

Build disparado para gerar o APK v5.
